# AI vs ML vs Deep Learning

> Create a simple comparison of Artificial Intelligence, Machine Learning, and Deep Learning using definitions, differences, and real-world examples.

### Objective
Build a clear understanding of the relationship between AI, ML, and Deep Learning.

### Tools
- Python
- Jupyter Notebook
- Markdown

### Comparison Table

| Feature | AI (Artificial Intelligence) | ML (Machine Learning) | DL (Deep Learning) |
|---|---|---|---|
| **Definition** | Machines mimicking human intelligence | Machines learn from data | Neural Networks with many layers |
| **Subset of** | Main field | Subset of AI | Subset of ML & AI |
| **Data Needed** | Less data, uses logic/rules | Medium data (thousands) | Huge data (millions) |
| **Hardware** | Normal computer | Normal computer | High GPU needed |
| **Real Example** | Google Maps, Siri, Alexa | Recommendation systems, Spam detection | Image recognition, Self-driving cars, ChatGPT |

### Real-world Examples
- **AI:** Google Maps, Siri/Alexa, Chess computer
- **ML:** Netflix/YouTube Recommendations, Spam Email Filter
- **DL:** Face Unlock, Self-driving Cars, ChatGPT, Google Translate

### How They Are Related
**AI > ML > Deep Learning**

AI is the biggest circle. ML is a method to achieve AI. Deep Learning is a powerful method inside ML that uses deep neural networks.

> **Analogy:** AI is the universe, ML is a galaxy inside it, Deep Learning is a planet inside that galaxy.
